# Nft-card-game
The NFT Card Game is a Node.js backend application (Game_Server) that uses the Hiero JS SDK to manage a collectible card game on the Hedera network. Every card is a Non-Fungible Token (NFT) on Hedera Token Service (HTS), giving each card provable on-chain ownership with no central database required for ownership tracking.
In other words, its a digital trading card game where players can collect, trade, and battle with unique cards, with all ownership tracked on the Hiero blockchain.
